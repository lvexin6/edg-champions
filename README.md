# EDG 无畏契约 · 2024 全球冠军赛冠军站

一个介绍 EDG 电子竞技俱乐部无畏契约分部 2024 年首尔全球冠军赛夺冠历程的静态网站。

## 内容

- **首页**：决赛 3:2 击败 Team Heretics 总览、夺冠之路时间线、夺冠时刻解说词、冠军五人组
- **选手页 ×5**：ZmjjKK（康康）、CHICHOO（球球）、nobody、Smoggy、S1Mon
  每人含主玩角色与位置、高光战绩、个性介绍、名场面、决赛武器库
- **冠军武库**：主战枪皮 TOP10 与刀皮排行榜
- **夺冠图集**：官方海报、决赛现场、捧杯瞬间

## 技术说明

- 纯静态 HTML + CSS，无框架、无构建步骤，双击 `index.html` 即可浏览
- 全站相对路径，整个文件夹可任意搬移
- 页面视觉为 2024 首尔冠军赛「超星闪耀 SUPERNOVA」主题（黑 / 金 / 紫）
- 星爆纹样、分隔线、盾形徽记等装饰图形由 CSS / SVG 绘制
