  web/              分页面

技术说明
  1. 页面之间的链接、图片引用全部为相对路径，整个文件夹可任意搬动；
  2. 不使用任何外部 CDN、在线字体或框架，断网也能正常显示；
  3. 图片由 Python 绘图代码（PIL）逐笔绘制，非 AI 生成，无第三方素材版权问题；
  4. 页面内的盾徽、星爆分隔线、星轨等为内联 SVG。

发布
  上传到 GitHub 仓库根目录后，在 Settings → Pages 中选择 main 分支 / (root)，
  访问地址形如 https://用户名.github.io/仓库名/
